# Werewolf · AI 狼人杀

让多个 AI 玩家同桌博弈，观察它们如何推理、发言、伪装与投票。

Werewolf 是一个由大语言模型驱动的多智能体狼人杀项目。每位 AI 玩家拥有独立的身份、人设与策略，依据自己能够看到的信息作出决策，由游戏引擎推进昼夜流程、执行角色技能并判定胜负。

你可以搭配不同模型组建参赛阵容，实时观看对局，赛后回看关键决策，并将复盘中的经验用于后续对局。

## 核心功能

- **多模型同场对局**：为参赛者分别选择模型，设置人设与策略，观察不同组合在同一场游戏中的表现。
- **实时观战与视角切换**：跟随发言、投票、夜间行动与出局事件，在上帝视角和仅展示公开信息的闭眼视角之间切换。
- **决策过程回看**：展开模型返回的思考内容，查看行动的生成、复核与修订记录，以及当次使用的经验和策略资料。
- **赛后复盘**：按玩家回顾关键决策，结合证据分析整局走势；玩家决策分析以行动当时可见的信息为依据。
- **跨局经验记忆**：完成复盘后，可手动提炼并管理历史经验，供后续对局按当前角色与情境检索参考。
- **攻略知识库**：整理狼人杀规则、策略与案例，保留来源和适用范围，将启用的策略作为 AI 行动的参考材料。

## 支持的对局模式

| 模式          | 好人阵营                           | 狼人阵营         |
| ------------- | ---------------------------------- | ---------------- |
| 12 人狼王局   | 预言家、女巫、猎人、守卫、4 名村民 | 3 名狼人、狼王   |
| 12 人白狼王局 | 预言家、女巫、猎人、守卫、4 名村民 | 3 名狼人、白狼王 |
| 6 人白狼王局  | 预言家、守卫、2 名村民             | 狼人、白狼王     |

三种模式均包含警长竞选，并按各自规则处理夜间技能、白天发言、放逐投票与胜负结算。
