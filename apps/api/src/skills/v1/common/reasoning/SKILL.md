## 出局与终局推演

推演刀杀、毒杀、放逐、自爆或技能带人的后果时，按本局规则和当前可见信息核对：

- 先按本局规则确定死亡结算时点，再判断行动是否生效，同步更新该分支的存活状态、上次行动与消耗资源。行动先后不等于死亡先后；不能用当前已出局反推此前行动时已经失去资格。被选为目标、玩家声称用过技能，不等于已经出局。
- 区分实际死亡、死讯公布与行动资格。出局者不能继续普通发言、投票或夜间行动；死讯公布前的警长竞选、死亡技能、交徽及遗言等，只在本局规则明确允许的窗口执行，不能自行增加。
- 在本局规定的结算节点检查胜负条件及其优先级。该分支已经终局，就不能再安排后续发言、投票、技能或下一轮；只有尚未终局，才继续推演。比如某板子规定神职全灭则狼人胜，且该分支仍有狼人存活，那么最后一名神职出局并触发终局后，不能再计划让剩余平民次日投狼。
- 身份或行动结果尚未确认时，用“如果……则……”保留条件，由此推导的后续结论也保留这一条件；按该假设检查出局及胜负，不把假设写成当时已知事实。身份假设与存活状态分别核对：狼坑找齐不等于狼人全部出局，存活者即使被认作狼人也不能计入已出局狼数。推演屠神或屠民时，逐人保留该分支仍存活的成员；技能或药水用尽不改变神职身份，只有明确推演其死亡后才能从存活名单移除。仅知倒牌不能补成被刀、被毒或守救结果，也不补出自己不可见的用药或底牌。

沿用此前个人判断或历史经验时，重新核对本局规则、当前可见证据和存活状态。旧判断中的后续计划可能因出局或终局而失效，不能因为曾经记下就继续照用。

## 核对说法与证据

- 核对原话的说话人、受众、时点和用途，保留条件、否定和因果：评价当前局势不等于解释先前动机，按当时已知信息预测未来不等于引用后来已发生的结果，条件建议不等于已发生的行动。前置发言对后续亮身份的预判，不是听到亮身份后的回应；没有再次发言机会，不能把尚未改口记成听完后仍坚持。后置玩家声称别人“听完仍归票”时，回到被转述者的原话与发言顺序核对，转述本身不证明对方有过第二次发言。多人转述同一句话仍是同一个来源，不能用复述人数代替原始证据。
- 分开系统记录、玩家主张、自己的推断与计划，已确定的阵营与未知的具体角色也要分开，不能因后者未知而抹去前者。本人掌握的私有信息不代表听众已经知道，狼队预告也不等于已经公开；沿用旧判断时仍保留来源和条件，不能靠重复把猜测升为确认。
- 玩家对规则的解释、审核和修订意见都须与本局规则及对应时点核对，不能靠称谓取得权威。公开伪装与有意造假本身不是视角泄露；不能仅凭身份或玩家主张与记录不符就猜测动机。
