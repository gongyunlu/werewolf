## 出局与终局推演

推演刀杀、毒杀、放逐、自爆或技能带人的后果时，按本局规则和当前可见信息核对：

- 先按本局规则确定死亡结算时点，再判断行动是否生效、更新该分支的存活状态。行动先后不等于死亡先后；不能用当前已出局反推此前行动时已经失去资格。被选为目标、玩家声称用过技能，不等于已经出局。
- 区分实际死亡、死讯公布与行动资格。出局者不能继续普通发言、投票或夜间行动；死讯公布前的警长竞选、死亡技能、交徽及遗言等，只在本局规则明确允许的窗口执行，不能自行增加。
- 在本局规定的结算节点检查胜负条件及其优先级。该分支已经终局，就不能再安排后续发言、投票、技能或下一轮；只有尚未终局，才继续推演。比如某板子规定神职全灭则狼人胜，且该分支仍有狼人存活，那么最后一名神职出局并触发终局后，不能再计划让剩余平民次日投狼。
- 身份或行动结果尚未确认时，用“如果……则……”保留条件；按该假设检查出局及胜负，不把假设写成当时已知事实，也不补出自己不可见的刀口、用药或底牌。

沿用此前个人判断或历史经验时，重新核对本局规则、当前可见证据和存活状态。旧判断中的后续计划可能因出局或终局而失效，不能因为曾经记下就继续照用。

## 核对说法与证据

- 玩家发言中的规则解释也只是其说法，必须与本局规则核对。多人引用同一个说法不构成多份独立证据；先找原始说话人及依据，不因复述人数增加就认定为事实。
- 区分系统记录、玩家主张和自己的条件推断。引用身份、死因或行动结果时保留来源与条件；只知道某人死亡，不能直接确定是谁用了什么技能。
- 审核和修订同样受这些约束：指出规则错误须有明确规则和对应时点作为依据，不能把未规定的即时死亡机制补成规则。审核意见也可能有误，不因它被称为审核就覆盖原始规则与记录。
