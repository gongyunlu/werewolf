以下规则只适用于本局这块板子，别套其他板型或赛事规则。

**角色配置**：预言家、守卫各一张，平民两张，狼人一张，白狼王一张。本局有警长。本局没有女巫，
也没有解药和毒药：凡是以女巫在场为前提的打法（比如守卫第一晚空守等解药）在这里都不成立。

**胜负**：狼人全部出局，好人获胜——这一条优先，两边同时达成时也算好人胜。否则，神职全部出局、
或者平民全部出局，狼人获胜。人数被压过去不等于终局，两边都没被屠完就接着打。

**所有玩家共同知道的能力**：

- 狼人夜间先商议、再各自提刀，队里取众数定刀口；不刀也是一票，自刀、刀狼都合法。商议说的话只有狼队看得到。
- 守卫每晚守护一人，可以守自己，但不能连着两晚守同一个人。守护挡得住狼刀。
- 预言家每晚查验一名还活着、不是自己、且此前没查过的人，知道他是狼人还是好人。结果当晚不公开，
  只能白天自己说出去。
- 白狼王白天自爆时可以额外带走一个还活着的人，带走谁由他自己定。

上面写的是公开能力，不表示你知道谁用了什么、谁查到了什么。别人公开说出来的仍然只是他的说法。

**夜间流程**：狼队商议 → 狼队提刀 → 守卫守护 → 预言家查验 → 天亮公布死讯。

**白天流程**：

- 第一天先选警长。想上警的人依次表态报名，报名完是一次自爆窗口，接着警上发言；全发完言再统一表态
  退水，退过水的人既不能被选、也没有票。剩下的人由没上警的玩家投票，票最多的当选。最高票并列就在
  并列者之间再发一轮言、再投一次，还平票就是本局没有警长。
- 竞选被打断过（有人自爆）的，第二天从退水表态接着走，报名和警上发言都跳过；退水表态之前还有一次
  自爆窗口。再被打断一次，警徽直接流失，本局没有警长。
- 选不出警长的情形：没人上警、上警的全退水、所有人都上警、警下玩家全部弃票。
- 发言顺序：有警长时由警长决定从左边还是右边开始，警长本人最后发言；没有警长时按当天时间的分钟
  个位定起点与方向，单数顺时针、双数逆时针，个位为 0 时从 1 号位起逆时针。当天有死者的话，起点
  改成座位号最小的那位死者，方向照旧。
- 每人一票，可以投任何还活着的人，包括自己，也可以弃票。票是同时投的，本轮结束前看不到别人投了谁。
- 警长那一票按一点五票计。
- 警长出局时（不论死于哪条路径），当场决定把警徽移交给一名还活着的玩家，或者撕掉；撕掉之后本局就
  没有警长了。
- 票最多且只有一个人时，他被放逐。最高票并列的，只在并列的人之间再发一轮言，再由没上台的存活玩家
  投票，且只能投台上的人，台上的人自己这轮不投。再平票、或者又全都弃票，今天不放逐任何人。
- 天亮公布死讯之后、常规发言开始之前，狼人有一次自爆窗口。自爆的人当场出局，这一天剩下的环节全部
  跳过，直接进下一夜。白狼王在这个窗口自爆时还要当场再带走一个人。窗口开在发言之前，问过就不再问：
  这一天不会再有第二次机会。

本局不设遗言，出局的人不再发言。
