---

以下规则只适用于本局这块板子，别套其他板型或赛事规则。

**角色配置**：预言家、守卫各一张，平民两张，狼人一张，白狼王一张。本局有警长。本局没有女巫，
也没有解药和毒药：凡是以女巫在场为前提的打法（比如守卫第一晚空守等解药）在这里都不成立。

**胜负**：狼人全部出局，好人获胜——这一条优先，两边同时达成时也算好人胜。否则，神职全部出局、
或者平民全部出局，狼人获胜。人数被压过去不等于终局，两边都没被屠完就接着打。

**所有玩家共同知道的能力**：

- 狼人夜间有多名存活队友时先商议两轮，再同时各自提刀，取众数定刀口；最高提名并列时随机选一个。
  不刀也是一票，自刀、刀狼都合法。商议只有狼队可见，提议不等于最终刀口。
- 守卫每晚可以守护一人，也可以空守；可以守自己，但不能连着两晚守同一个人。守护挡得住狼刀。
- 预言家每晚查验一名还活着、不是自己、且此前没查过的人，知道他是狼人还是好人。结果当晚不公开，只能白天自己说出去。
  有合法目标时必须选择一人，不能主动空验；只有没有任何合法目标时，系统才跳过查验。
- 白狼王白天自爆时可以额外带走一个还活着的人，带走谁由他自己定。
  能带走的目标必须是实际存活的人：目标夜里被刀、死讯还没公布，也已经出局，选到这样的人这一枪空放。

上面写的是公开能力，不表示你知道谁用了什么、谁查到了什么。别人公开说出来的仍然只是他的说法。

**信息边界**：系统会告知本人底牌和自己的技能记录。预言家只获得查验对象的好人或狼人结果，不获得具体角色；
守卫只知道自己守谁，不知道刀口。狼队知道队友和实际刀口，不知道好人的具体角色。平民没有私有技能信息。
出局不统一翻开身份牌，夜间公告不公开具体死因。公开发言和摘要不是系统认证；同票、金水主张、平安夜都不能单独证明身份。

**夜间流程**：狼队商议 → 狼队提刀 → 守卫守护 → 预言家查验 → 天亮（暂不公布死讯）。

第一夜在第一次白天之前。首夜查验完成后才天亮、报名上警，所以查验时还没有上警名单、警上发言或警长票型。
这些信息在白天产生后可以用于后续判断和下一夜行动，不能作为首夜行动时已经知道的信息。

**白天流程**：

- 第一天先选警长，夜间死讯尚未公布。所有未公开出局的玩家同时报名；昨夜中刀者仍可上警、
  发言、退水，原警下玩家仍可投票。无人上警则无警长，仅一人上警则直接当选。
- 多人上警时，先询问一次自爆，再依次警上发言；全部发言结束后统一退水。
  报名没有先后顺序；警上第一个发言不等于第一个报名，也不表示更早作出上警决定。
  警长投票权只属于原警下玩家。上警者无论是否退水都没有警长投票权；退水只放弃候选资格。
  剩余候选人只有一人则直接当选，无人则警徽流失；多人由原警下玩家投票，唯一最高票当选。
  最高票并列则进入 PK，开始前再询问一次自爆，然后平票者发言、原警下玩家再投一次。再平票则警徽流失。
- 首轮竞选被自爆打断，保存原上警名单及剩余候选资格，公布夜间死讯、结算死亡技能后入夜。
  次日仍先续选、后公布该夜死讯：排除此前已公开出局者，不重新报名、不补警上发言，直接进入退水。
  续轮退水和续轮 PK 开始前各询问一次自爆；再次自爆则警徽流失，公布夜间死讯并完成必要结算后入夜。
  已退水或被 PK 淘汰者不会重新获得候选资格，也不会获得警下投票权。
- 无候选人则警徽流失，仅剩一名候选人则直接当选；需要投票但没有警下投票人，或警下全部弃票，也无警长。
  警徽流失后本局不再重选。
- 竞选或续选结束后，公布夜间死讯，统一落实该批出局，再结算符合条件的死亡技能及连锁，最后处理警徽。
  昨夜中刀者若当选警长，在公布其出局后处理交徽或撕徽。
- 自爆、技能带人、放逐都即时宣布出局。已经在白天出局的人从夜间待公布名单中移除，不再重复公告或结算。
  白狼王夜里被刀、天亮死讯还没公布时仍可自爆；本局没有女巫，不存在吃毒封住带人的情形。
- 发言顺序：有警长时由警长决定从左边还是右边开始，警长本人最后发言；没有警长时按当天时间的分钟
  个位定起点与方向，单数顺时针、双数逆时针，个位为 0 时从 1 号位起逆时针。当天有死者的话，起点
  改成座位号最小的那位死者，方向照旧。起点座位本人已出局或没上警时，沿该方向顺延到最近的可用座位。
  left 是逆时针、座位号递减，right 是顺时针、座位号递增，均环绕并跳过已出局者。警上与 PK 的发言顺序都由系统给出，PK 取其中的平票者逆序排列。
- 每人一票，可以投任何还活着的人，包括自己，也可以弃票。票是同时投的，本轮结束前看不到别人投了谁。
- 警长那一票按一点五票计。
- 警长出局时（不论死于哪条路径），在该轮死亡技能结算后决定把警徽移交给一名还活着的玩家，或者撕掉；撕掉之后本局就
  没有警长了。
- 票最多且只有一个人时，他被放逐。最高票并列的，只在并列的人之间再发一轮言，再由没上台的存活玩家
  投票，且只能投台上的人，台上的人自己这轮不投。再平票、或者又全都弃票，今天不放逐任何人。
- 警上发言、续轮退水、竞选 PK、常规发言和放逐 PK 各阶段开始前只询问一次自爆，不在每人发言之间重复询问。
  自爆者立即出局，跳过当天剩余发言和放逐；尚未公布的夜间死讯、符合条件的技能和警徽结算仍需完成，再进入黑夜。
  已经产生警长后，普通自爆不会自动吞掉警徽；只有警长出局才需要交徽或撕徽。
- 每次出局结算后检查胜负；已终局就停止后续技能、交徽和入夜。

本局不设遗言，出局的人不再发言。

发言里的验人计划、退水意向、归票和枪口都只是主张；只有对应操作窗口的提交及后续结算才会改变局面。
空刀、空守、弃票和技能不带人是否可选，以当前完整合法选项为准；策略建议不能增加操作窗口或权限。
