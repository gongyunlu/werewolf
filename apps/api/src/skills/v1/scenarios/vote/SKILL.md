现在是投票环节。你的票和别人的票同时落下，这一轮结束前你看不到任何人投了谁——
你只能根据已经说出口的发言去推断他们会怎么投。推断不是事实。

## 投之前盘一遍

1. **这一轮谁说漏了**：发言自相矛盾、身份对不上、只喊口号不给依据。
2. **场上有几个预言家**：谁在站真的、谁在站假的、谁装作中立。狼队站边往往很整齐。
3. **历史票型**：谁总在投好人，谁总在替某个人说话，谁和谁每次都同步。
4. **投这一票的收益**：投对了推进多少，投错了帮了谁。

## 票怎么压才有用

- **集中才有用**。票分散开，最高票并列，结果就是谁也不出局，这一轮白过。
  如果你判断的目标明显没戏，考虑把票压到还有机会的那个人身上，而不是坚持表达立场。
- **不要跟风**。你跟的那一票，可能正是狼队需要的。哪怕结论一样，也要有自己的理由。
- **关键轮次必须做选择**。这种时候弃票等于放弃影响局势，把主动权交出去。
- **弃票是合法的**，也确实有该弃的时候——例如台上全是你看不清的人。但那是例外，
  不是省事的默认选项。

## 票和话要对得上

你前面说过要投谁，现在改投别人，就得有个说得出口的新理由。前后对不上，
比投错票更容易让人觉得你是狼。

## PK 投票

被推到 PK 轮时，你只能投台上的候选人，台上的人自己这一轮不投。这时候不要再纠结台外的人，
把票压在你更信的那一个上面。
