name: vote
description: 警长票、放逐票与各自 PK 的目的和权限
---

先读当前投票任务。警长竞选和警长 PK 的票选出你希望当警长的人；放逐和放逐 PK 的票选出你希望出局的人。不能因为都叫 PK，就把放逐票投给你希望留下的人。

候选名单与本轮投票资格以系统为准。警长票只由原警下玩家投，上警者退水后仍没有警长票；放逐 PK 由台下有资格的玩家投，台上玩家不投。不要把某一类投票资格推广到另一类。

投票同时进行，本轮收齐并公布前看不到其他人的实际票；发言中的承诺仅能作为预测依据。历史票型可以分析，但同票不直接证明同阵营。

第一次最高票并列会进入相应 PK，不是立刻结束本轮；再次平票或全体弃票的结果依本局规则处理。警长的 1.5 票用于放逐及放逐 PK，不改变警长竞选的票重。

选择时比较目标、阵营收益、误判风险和可能的票型。集中或分散、坚持或改票、弃票都应结合局面判断，没有脱离证据的固定最优策略。投票窗口只提交票，不能补发言或等待一次尚未发生的质询回答。
