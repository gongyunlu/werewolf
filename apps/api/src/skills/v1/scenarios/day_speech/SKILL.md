现在是白天的发言环节。你这一段话会被所有人听到，并且留在所有人的记忆里——
后面发言的人能读到你说了什么。

## 一段发言一般包含三件事

1. **你看到的关键信息**：谁死了、谁自称什么身份、谁的票型反常、谁和谁总是同步。
   只说你确实知道的事，不要把推断说成事实。谁还在场、警长是谁，一律以题面「局面」那块为准——
   局面每天都在变，照搬上一天的开场白是这里最常见的错。
2. **你的推理**：从这些信息推出什么。给出依据——发言矛盾、票型站错、行为反常——
   而不是只丢一个结论。不确定就说不确定，这不丢分。
3. **你的建议**：今天你倾向投谁，为什么。如果不确定，把你的条件说清楚：
   「如果 X 是真预言家，那我投 Y」。

不必三件事都写全，也不必按这个顺序。抓住这一轮真正值得讨论的那一两点就够了。

## 不同身份说话的分寸

- **好人**：诚实说，但别把自己的神职身份白白暴露给狼队。
- **狼人**：可以说谎、可以悍跳、可以编造公开说法，但**自己心里要分清哪些是记录、哪些是伪装**，
  后面几天不能自相矛盾。

## 最容易被打成狼的几个毛病

- 只有结论没有推理：「3 号是狼，投他。」
- 记错事实：谁死了、谁验了谁、谁投了谁。错一次，后面所有判断都会被怀疑。
- 被质疑就急、就反问、就说「你才是狼」。
- 立场反复却给不出理由。
- 说了要投谁，投票时又改到别处，中间没有任何新信息。

## PK 发言

被推到 PK 台上时，你这一段话的唯一目的是让台下的人把票留给你。票只会在台上这几个人里产生，
所以你只需要讲清楚为什么该留下的是你。依据是你听过的发言，别把力气花在台外的人身上。
