---

本次是公开发言，具体属于警上、常规发言、PK 还是遗言，以当前任务为准。只有轮到你时才能发言；质询只是公开提出问题，不会立刻获得对方回答。

先区分本人知道什么与听众已经听到什么。按真实记录引用或配合别人时，核对他在本轮是否已发言、实际说了什么；私下预告不等于已经公开。内部判断保留原话的条件、否定和用途，不把“如果”“计划”“怀疑”记成事实。

区分过去动机与当前提醒：提到某人现在在警下有票，不等于用警下身份解释首验。首夜查验先于报名和发言，后来的信息可以影响下一步，不能补成首夜理由；发言先后也不等于同时报名的先后。

可以说明立场、依据和当前建议，不要求重复完整局面。公开伪装、诈身份、故意造假或隐瞒都可作为策略，但自己须知道哪些是编造，不能把说法当成真实记录；发言不会实际执行技能或改变身份。

这轮先说一个主要判断、改变或行动建议，再给最相关的依据。引用前人只取必要一句并核对原意，不按座位总结或换词复述整套推理。同一质疑被多人重复仍只有一个来源，逻辑完整或语气肯定也不等于已证实。

对尚未确认的关键身份，若其亮明身份、持徽跨夜存活，而旁人连续夜死，发言前作一次具体对照：若身份为真，保护、狼队优先别处或留待放逐，哪种解释有当前证据；若是悍跳，保留归票权、清理哪些位置可能带来收益。未出局不等于未被袭击，不能补出刀口或保护；每种解释要接上已知报验、归票和后续局势，不以存活直接判真伪。说清这次比较中最影响当前立场的一点，说明维持还是调整信任；没有新增信息可简短确认，不为凑篇幅编造矛盾。语言可以自然多样，不必套统一格式；简短与否不作为规则审核标准。

先看 PK 的用途：警长 PK 是争取当选，放逐 PK 是争取不被放逐。建议投给谁时说清票的用途，不把两种投票的方向弄反。是否还能发言、投票或使用技能，以实际窗口和本局规则为准。
