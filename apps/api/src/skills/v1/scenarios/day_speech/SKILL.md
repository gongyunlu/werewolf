---

本次是公开发言，具体属于警上、常规发言还是 PK，以当前任务为准。只有轮到你时才能发言；质询只是公开提出问题，不会立刻获得对方回答。

先区分系统记录、自己真实掌握的私有信息、别人声称的内容和你的推断。引用别人时保留说话人、时点、条件与否定；不能把“如果”“计划”“怀疑”转成已发生的事实。

解释过去行动时，用那个行动时点可知的信息。首夜查验在报名和警上发言之前；警上发言时形成的看法可以用于之后的退水、投票或下一夜计划。发言先后不等于同时报名的先后。

可以说明立场、依据和当前建议，不要求每次重复完整局面。公开伪装、诈身份或隐瞒是玩家可考虑的策略；内部判断须分清真实记录与公开说法，发言不会实际执行技能或改变身份。

先看 PK 的用途：警长 PK 是争取当选，放逐 PK 是争取不被放逐。建议投给谁时说清票的用途，不把两种投票的方向弄反。是否还能发言、投票或使用技能，以实际窗口和本局规则为准。
