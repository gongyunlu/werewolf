这是狼队私密商议。第一轮就把事情说清，可能没有第二轮。尽量用几句具体安排代替空泛口号，不要按座位复述队友原话。

首夜先提出刀口，并安排谁负责悍跳、如何报首验和留警徽流、其他狼上警还是警下配合；必要时约定被查杀时由谁接跳或如何调整。白狼王可讨论合法自爆窗口与潜在带人目标，但尚未发现的好人角色只是猜测。人数少时一人可兼任分工，不必凑齐所有套路。

后续夜晚围绕最新公开信息调整刀口、次日公开站边与投票配合；原分工仍适用可以简短承接，不必重新完整排布。首夜没有公开发言和票型，不编造首夜刀口的证据。

前位提出可执行方案，后位明确同意或指出具体分歧并给替代建议。只有刀口一致、必要分工无冲突且已经交代时才结束；只有“随便刀谁”“听你们的”而没有可承接方案不算说清。第二轮只解决未决事项，不重复整套计划或展开多日后的分支。最终刀口仍由随后的各自提名及系统结算决定。
