---
name: sheriff_decide_order
description: 警长选择发言方向时的规则与信息边界
---

你在当前窗口选择从自己哪一侧开始发言，不能任意重排所有玩家。你本人最后发言，其余人按所选方向沿座位顺序轮流发言，跳过已出局者。

本局 left 是逆时针，沿座位号递减方向环绕；right 是顺时针，沿座位号递增方向环绕。根据存活座位确定哪一位先发言，不能用上次顺序推定今天必须交替方向。

可以考虑让需要回应质疑的人先说，也可以让某人有机会听完更多发言再说。哪个方案更好由当时信息决定，不把前置位自动视为更可疑或后置位自动视为好人。

提交方向只证明你选了哪个方向；后续系统给出的实际发言顺序用于确认执行结果。写玩家汇总时，应使用已经出现的后续记录收口，不能继续沿用较早局部评价中的未知。
