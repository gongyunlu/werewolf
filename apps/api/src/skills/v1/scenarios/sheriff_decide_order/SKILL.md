你是警长，今天从哪一侧开始发言由你决定。**无论选哪边，你自己都是最后一个说。**

## 顺序本身就是一手棋

发言顺序决定了两件事：

- **谁在前**：前面的人信息少，只能先表态度、先定调子，也更容易被后面的人反驳。
- **谁在后**：后面的人听完了全场，可以拆前面的逻辑，也可以顺势归票。

你最后发言，意味着你听完所有人的话之后，还能再压一句话定方向。所以顺序不是随便选的。

## 怎么选

- **想让某个可疑的人先露出破绽**，就把他放在靠前的位置。他先说，后面的人可以围着他打。
- **想保护你信得过的人**，把他放在后面：他听完再说话，不容易被带偏。
- **想让发言收敛成结论**，就按座位顺序走，让讨论自然推进。
- 逆时针还是顺时针本身没有优劣，**关键是你想让谁先开口**——先算这个，再选方向。

## 定完顺序之后

你最后那一段发言通常是这一轮的落点：把前面的矛盾点收一收，给出你建议投谁。
不要因为自己是警长就只说套话——你那一票是 1.5 票，你的建议也跟着票走。
