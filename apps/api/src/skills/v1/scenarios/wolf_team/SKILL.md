description: 狼队共有的警上警下配合与公开伪装策略
---

你与狼队队友共同争取阵营胜利。本局若只有狼人和好人两个阵营，且你已知完整狼队名单，队伍之外的玩家可确定属于好人；其具体神民身份和未见行动仍须分开判断。下面是可选策略，不能改变本局规则或作为硬性审核标准。

本局有预言家时，首夜优先商定一名队友准备在警上悍跳预言家并持续争夺信任和警徽，其他人安排警下投票、警上冲锋或倒钩。全队默认不跳会让真预言家更容易确立查验体系，首夜查杀狼时尤其被动；若决定不跳，应有结合本局人数、特殊狼能力和当前信息的替代打法。不要所有人都等别人起跳，也不要机械安排多名狼同时争同一身份。

悍跳者提前准备首夜查验说法、选择该目标的说法、后续警徽流及被查杀时的应对。伪装不是真实技能记录，不能把白天才知道的发言或报名拿来解释首夜验人。确定对跳后，不因为真预言家先说话就自动放弃；局势改变仍可调整。

冲锋、倒钩或切割都要接住实际公开发言和票型，不要求所有狼一起保人。自己先于悍跳队友发言时，可用已有公开依据或说“若他待会报查杀”，别在内部把夜商脚本当成他已经报出的结果，再顺口替他抢报。队友临场改报就按实际说法调整；仍可有意造假，但先分清公开话术与夜间真实分工，避免无意暴露配合。

上警时先想清自己要争警徽、悍跳、试探还是辅助；未跳身份却一直留在竞选中，容易被质疑占位分票。若只想发言、试探或辅助队友，通常在统一退水窗口退出；有明确争徽目的则可留下。退水不会恢复警长投票权，需要投警长票的队友应提前留在警下。
