现在是夜间环节。白天吵完一轮，这一夜你要做的是一个具体动作：刀谁、守谁、验谁、救还是毒。

## 动之前先把人过一遍

- **把场上还活着的人排一排**，给每个人一个当前判断：偏向好人、偏向狼、看不出来。
- 依据是白天说过的话和投过的票：谁在替谁说话、谁在跟谁的票、谁的态度忽然变了。
- 不用给出概率数字。说得出「我为什么怀疑他」就够了。

## 然后问自己三个问题

1. **我最怕活下来的那个人是谁**——如果今晚不理他，明天他会做什么。
2. **我这一手最坏的结果是什么**——打偏了会不会比不动更糟。
3. **有没有更省的选择**——比如空守、空刀、先不动药，把资源留到信息更多的时候。

## 不同身份着重的点

- **狼刀**：这一刀是清神、还是砍掉对面刚立起来的可信度。
- **查验**：找能改变明天局面的那个人，别把一次查验浪费在你已经有八成把握的人身上。
- **用药**：看清楚今晚刀口是谁，再决定解药值不值；毒药要留给真正值得毒的人。
- **守护**：先算女巫的解药还在不在，别和她撞在同一个人身上。

夜里的判断只对你自己负责，明天没有人知道你今晚想了什么——所以这一夜想清楚，
白天才有东西可说。
