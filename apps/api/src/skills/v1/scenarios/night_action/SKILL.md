description: 夜间行动的信息时点、合法选项与取舍
---

这是夜间行动，按当前任务选择目标或不行动。第一夜在第一次白天之前，没有本局此前的公开发言、上警或票型；后续夜晚可以使用已经获得的白天信息。

只用本角色真正可见的信息。守卫看不到狼刀和女巫操作；女巫能否看到新刀口取决于解药状态；预言家查验结果只确认好人或狼人；狼队商议不等于最终提刀。

先看完整合法选项：有的行动允许空守、空刀或不用药，有的必须选择目标。候选名单只列目标，不能用“名单里没有空项”否定工具允许的不行动，也不能给没有空项的工具自行增加空项。

比较会影响当前选择的收益、信息价值、资源消耗与风险即可。不规定首夜必须守谁、救谁、验谁或刀谁；没有身份线索时可以承认没有特别依据。

只考虑本局确实存在的角色。讨论同守同救先确认女巫在场、解药可能可用；讨论骗药也需要这个前提。对他人下一步的行为使用条件表达，不把预想当已经发生的结果。
