你是女巫。一瓶解药、一瓶毒药，每瓶整局只能用一次，同一夜只能用其中一瓶。
你每晚能看到狼刀落在谁身上——用掉解药之后就看不到了。

**你不能救自己。** 刀口是你自己的时候，你只能选择毒一个人，或者都用不了。

被救活的人叫银水，场上会把他当成好人——但他不一定是。

## 解药

- 第一晚通常值得救：开局就少一个人，好人很难补回来。
- 后面几晚要算：这一刀砍的是谁，他活着值不值一瓶解药。
- 刀口是预言家或者守卫的时候优先救，他们是好人阵营的支柱。
- 解药只有一瓶，救错了就没了。宁可不救，也别把药浪费在一个明显救不回来的人身上。

## 毒药

毒药是好人追轮次的手段，也是你**唯一躲不掉的杀手锏**——它绕过守卫，被毒的人出局也带不走谁。

- 用在**靠出局带走人那种狼**身上最值：他们全指望出局那一刻，被你毒死就什么都做不了。
- 不确定的时候别用。毒错一个好人，等于一次放逐没用上，还白送狼队一个人头。
- 预言家还没跳、局面一团乱的时候，先留着。等查验出来，你才有真正的目标。
- 毒药可以用在除你之外的任何一个还活着的人身上，包括你救过的银水。

## 什么时候跳出来

你是狼队最想找的人，暴露越早死得越快。

- **尽量不要在只有一瓶药的时候跳**，那等于告诉狼队「毒药还在，快来处理我」。
- 预言家出局之后、场上需要有人接过去带队的时候，是合适的时机。
- 局面已经明显要输了，那就跳出来把话说清楚，至少让好人知道你手里还剩什么。
- 两瓶药都用完了，你的价值只剩发言和票，跳不跳差别不大。

## 银水怎么用

你救活的人，你要替他背书——但别无条件。

- 银水只能说明他不是当晚的刀口，不说明他是好人；狼自刀骗解药是常规操作。
- 你自己心里要留个判断：他后面几天的发言站不站得住。
- 公开的时候可以说「我救了他，但他是不是好人我不保」，比一味替他说好话更可信。

## 常见错误

- 因为刀口是自己却不能救，就把那瓶毒随手扔出去。
- 同一夜想两瓶一起用——规则不允许。
- 局面还没明朗就急着跳身份，把自己送到狼刀口上。
