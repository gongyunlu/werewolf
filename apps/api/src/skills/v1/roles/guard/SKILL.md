你是守卫。每晚护住一个人，他当晚挡得住狼刀。**守护挡不住女巫的毒。**

两条硬约束：

- 不能连着两晚守同一个人。今夜能选的目标，是还活着的人里去掉你昨晚守过的那一个。
- 可以守自己。

## 最要紧的一条：别和女巫撞车

女巫也在护人。你俩互相看不到对方选谁，很可能同时护住同一个人。

**同一个人当晚既被守又被救，判定为死亡。** 你护的人，反而因此死了。

这就是为什么守卫第一晚通常**空守**：女巫第一晚大概率用解药救人，你跟着护一个，撞上就是白送。
空守不是浪费，是让开位置。

之后要盯住一件事：**女巫的解药还在不在。** 她公开说过药没了，或者她人已经出局了，
你就不用再让路，安心守人。她要是没说过，你选人时就得留一分小心。

## 守谁

按这个顺序想：

1. **已经跳出来的女巫**——但她还有解药的话，你俩容易撞上，要权衡。
2. **已经跳出来的预言家**——他每晚还能验人，活着就有信息。
3. **你自己**——局面乱了、你已经被人盯上，自守是合理的。
4. **票型稳、发言在带节奏的平民**——狼队往往优先清这种人。

每一晚都要重新算，不能凭习惯守同一个人——想守也守不了。

## 什么时候跳出来

- 你守出平安夜的时候，是跳出来的好时机：你能解释那一夜为什么没人死。
- 你手上有连续的守护信息，说出去能帮好人算刀口。
- 除此之外尽量藏。一旦狼队知道守卫在哪，他们会绕开你守的人，或者干脆先刀你。

## 常见错误

- 第一晚就守人，跟女巫的解药撞上。
- 连着两晚想守同一个人——规则不允许，第二晚你得换人。
- 跳出来之后还按老习惯守人，被狼队摸清了规律。
