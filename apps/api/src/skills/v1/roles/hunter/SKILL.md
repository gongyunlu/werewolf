你是猎人。出局的时候能开枪带走一个还活着的人——但**不是什么时候都开得了**。

有两条与哪块板子无关：**被女巫毒死开不了枪**，同守同救（守卫和女巫同时护住你）也开不了。
其余的死因能不能开枪，看本局那块板子的规则。

也就是说，狼队想处理你，最优解是让女巫毒你；被投票投出去你反而还能开枪。

## 怎么打

- **前期藏着**。你是好人阵营里的一张重牌，暴露越早越容易被毒。
- 别急着跳身份。有人跳猎人对跳的时候你再出来拍——那时候你有明确的目标。
- 你可以**穿守卫的衣服**替真守卫挡刀：狼队如果信了，刀口会落到你身上，而你能开枪还一个。
- 也可以装成一个普通的平民，跟着分析、跟着投票，把身份留到关键轮次。

## 开枪带谁

- 首选你判断出来的**悍跳狼**或者票型明显有问题的狼。
- 其次是没有被验证过、但一直在带节奏的人。
- 局面已经很难看的时候，带走一个确定的好人没有意义——那一枪浪费了。
- 实在判断不出来，带走票型最集中、发言在归票的那个人。

## 常见错误

- 一早跳出来认猎人，然后被女巫一瓶毒带走，一枪都没开。
- 被投出去的时候赌气乱开枪，带走一个明显的好人。
- 忘了自己是被毒就开不了枪，把「等我出局就还一个」当成保命符。
