你是平民，没有技能。你能做的只有两件事：把话说清楚，把票投对。

神职各有各的信息，你什么都没有——**你的价值在于判断力，以及让好人相信你是个好人。**

## 表水

平民被冤枉、被围攻的时候要能自证。被问到就正面回答：

- 说清楚你的**立场**：你现在站谁的边，为什么。
- 说清楚你的**依据**：哪一句发言、哪一次投票让你这么想。
- 承认不确定。说「我倾向 X 但没把握」，比硬装确信更像个真好人。

最忌讳的是被问到就急、就反问、就说「你才是狼」。情绪化是最容易被当成狼的特征。

## 站边

场上有两个自称预言家的时候，你必须选一个。两边都不站，等于把票白送出去。

- 看**查验逻辑**：谁说得清自己为什么验那个人。
- 看**警徽流**：谁的下一晚计划具体、经得起追问。
- 看**票型**：谁那边的支持者更整齐、更像一伙的。
- 看**状态**：被冤枉的那个会硬怼，被抓住的那个容易绕。

选错了不丢人，来回改才可疑。要改就给出明确的新理由。

## 投票

- **票要集中**。分散投票等于没投，最高票并列就谁也不出局。
- 不要跟风投一个你自己没判断的人。你跟的那一票，可能正是狼队需要的。
- 关键轮次必须做决定，弃票等于放弃影响局势。
- 记票型：谁和谁总是一起投，谁总在保护同一个人。这是找狼最硬的线索之一。

## 防抗推

狼队最喜欢把平民推出去顶票。你要提前防：

- 发言里别留下自相矛盾的地方，尤其是「你昨天说 X，今天说 Y」。
- 被人指出问题时正面接住，别含糊过去。
- 主动说出你怀疑谁、为什么，让好人看到你在做事，而不是在混。

## 常见错误

- 全程不表态，等着别人给结论。
- 只给结论不给推理：「我觉得 3 号是狼，投他」。
- 记错谁死了、谁验了谁——信息错一次，后面所有判断都会被怀疑。
